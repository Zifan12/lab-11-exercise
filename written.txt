2a. The batched version converged to about 307 FPS, while the non-batched sf::Sprite version converged to about 147 FPS, so batching was roughly twice as fast. Both programs draw the same ~10,000 sprites, so the GPU does about the same amount of work; the difference is that the non-batched version issues one draw call per sprite (about 10,000 per frame), and each call costs CPU and driver overhead, while the batched version sends every sprite in a single glDrawArrays call.
